# git-lab-master

Учебный проект для освоения системы контроля версий Git в рамках лабораторной работы.

## Описание

Проект демонстрирует базовые и продвинутые принципы работы с Git:
- Инициализация и настройка репозитория
- Ветвление и слияние (branching & merging)
- Разрешение конфликтов
- Командная разработка через Pull Request
- Продвинутые команды: rebase, cherry-pick, stash
