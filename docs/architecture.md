# Архитектура проекта

## Обзор

Проект построен по модульной архитектуре с разделением ответственности между компонентами.

```
┌─────────────────────────────────────────────┐
│                  Клиент                      │
│           (HTTP / CLI / Tests)               │
└───────────────────┬─────────────────────────┘
                    │
┌───────────────────▼─────────────────────────┐
│              Слой сервисов                   │
│  ┌─────────────────┐  ┌──────────────────┐  │
│  │  AuthService    │  │  PaymentService  │  │
│  └────────┬────────┘  └────────┬─────────┘  │
└───────────┼────────────────────┼────────────┘
            │                    │
┌───────────▼────────────────────▼────────────┐
│              Слой моделей                    │
│  ┌──────────┐  ┌──────────┐  ┌───────────┐  │
│  │  User    │  │ Payment  │  │  Invoice  │  │
│  └──────────┘  └──────────┘  └───────────┘  │
└─────────────────────────────────────────────┘
```

## Компоненты

### src/auth/

| Модуль | Назначение |
|--------|-----------|
| `login.py` | Аутентификация пользователей, хэширование паролей |
| `register.py` | Регистрация, валидация данных |

**Принципы безопасности:**
- Пароли хранятся как PBKDF2-HMAC-SHA256 хэш с солью
- Сравнение хэшей через `hmac.compare_digest` (защита от timing attack)
- Валидация сложности пароля при регистрации

### src/payment/

| Модуль | Назначение |
|--------|-----------|
| `payment.py` | Жизненный цикл транзакции: PENDING → CONFIRMED / FAILED / REFUNDED |
| `invoice.py` | Формирование счёта с расчётом НДС |

**Диаграмма состояний платежа:**

```
[PENDING] ──confirm()──▶ [CONFIRMED] ──refund()──▶ [REFUNDED]
    │
    └──fail()──▶ [FAILED]
```

## Тестирование

Тесты расположены в `tests/` и покрывают:
- Хэширование и верификацию паролей
- Сценарии входа (успех / неверный пароль / неизвестный пользователь)
- Жизненный цикл платежа
- Расчёты в инвойсе

Запуск: `pytest tests/`

## Соглашения по коду

- Стиль: PEP 8
- Типизация: аннотации типов (`typing`)
- Исключения: явные типы (`ValueError`, `RuntimeError`, `KeyError`)
